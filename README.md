Read me # Beginner C Programs

This repository is a personal learning space for practicing C programming fundamentals.  
The programs here are written while studying C concepts from a reference handbook and experimenting with my own ideas as they arise.

Some programs directly apply concepts being learned, while others are small logical experiments created to better understand how C behaves in real situations.

The focus of this repository is learning through practice, not producing final or optimized solutions.

---

## Learning Approach

- Concepts are learned from a structured C programming reference
- Code is written to apply those concepts immediately
- New ideas and variations are explored freely
- Programs are added whenever something new is learned or tested

There is no fixed order or completeness guarantee for the programs. Each file represents a snapshot of understanding at that point in time.

---

## What You’ll Find Here

- Basic and intermediate C programs
- Practice code based on newly learned concepts
- Simple logic-building experiments
- Menu-driven and control-flow based programs
- Gradual improvement in structure and clarity over time

The repository grows organically with learning progress.

---

## Concepts Used

Depending on the program, this repository may include work related to:

- Input and output
- Variables and data types
- Conditional statements
- Loops
- Switch-case control structures
- Mathematical logic
- User-driven program flow

Future programs may include additional concepts as learning continues.
